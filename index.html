How Rheinplan stays useful

Small print, clearly said.

This calendar starts with organiser-published listings. A scheduled daily job checks the configured official pages, accepts Ticketmaster results when an API key is set, and can ingest Instagram events through the account owner’s approved Meta access token.

It never claims completeness: event sites change, and Instagram does not permit reliable public scraping. Each card keeps its source link so you can confirm details before heading out.
